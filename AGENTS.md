> [!IMPORTANT]
> This repository is connected to a hosted deployment workflow. Avoid rewriting
> published git history — force pushing, rebasing, amending, or squashing
> commits that are already pushed — as it can disrupt the connected branch and
> cause the user to lose project history.
>
> Commits pushed to the connected branch sync back to the deployment workflow
> and appear in the editor, so keep the branch in a working state.
